# CoreWave

A clean, modern, fully responsive landing page for a digital services agency. Built with React and Tailwind CSS, designed to look great on phones, tablets and desktops.

🔗 **Live demo:** [core-wave-saiful.vercel.app](https://core-wave-saiful.vercel.app/)

<img width="100%" alt="CoreWave full page preview" src="https://github.com/user-attachments/assets/2de640c9-bfb0-4106-954e-5f3df43de6de" />

## Features

- **Fully responsive:** a pixel-perfect desktop design that adapts smoothly down to small phones
- **Smooth navigation:** menu links scroll to each section, with a mobile hamburger menu
- **Filterable projects:** switch between Mobile App, Web Development, UI/UX, Graphic Design and Motion Graphic
- **Testimonial slider:** auto-playing client reviews that pause on hover
- **Scroll to top** button and clean, reusable components

## Built With

React 19 · Vite · Tailwind CSS v4 · React Slick · React Icons

Designed in Figma and deployed on Vercel.

## Run Locally

```bash
npm install
npm run dev
```

Then open the local address shown in the terminal (usually `http://localhost:5173`).
